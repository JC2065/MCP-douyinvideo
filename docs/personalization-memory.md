# 个性化记忆：越用越懂用户（第128次）

目标：选题搭档“TA”随使用逐步了解用户；更换模型连接或 API Key 后，对用户的了解完整保留。

## 为什么换模型不丢

画像不存在任何模型或供应商那里，而是 YOUAI 服务器上的 `auth/user-profile.sqlite`，由确定性规则计算（证据门槛、时间衰减、长度上限），不依赖某个模型去“总结”。每次对话把画像渲染成一段不超过上限的文字，放进 `learnedProfile` 交给当前配置的连接。测试 `test_profile_survives_switching_model_connection` 验证切换到另一个连接后发送的画像完全相同。

## 学什么

| 信号 | 来源 | 默认权重 |
| --- | --- | --- |
| 喜欢 | 灵感页选题卡片“👍 喜欢” | 3 |
| 不想要 | 选题卡片“不想要” | 3（计入“不想要的方向”） |
| 采纳 | 点“用这个主题创作”（仅登录用户） | 2 |
| 保存的作品 | 账号名下生成任务的受众、语气、目标 | 1 |

选题词由服务器 jieba 提取（保留实词，过滤“推荐/搞定/怎么办”等泛词与数量词）；同一选题同一反馈只计一次；涉及健康、财务、证件、宗教、政治等敏感词和长数字一律不入画像。同一方向既有喜欢又有不想要时按净值保留一侧。

## 规则参数（中台“热点推荐 → 个性化记忆”，版本化可回滚）

`enabled` 总开关 · `minEvidence` 写入门槛（默认3次）· `halfLifeDays` 衰减半衰期（30天）· `maxProfileChars` 画像上限（400字）· `historyTurns` 带入最近对话轮数（6）· `creationRecords` 带入创作记录条数（10，上限20）· `exploreCount` 每次推荐中跳出习惯的新方向数量（1）· 四类信号权重（0–10）。

## 用户控制

小程序“偏好设置 → TA 的了解”（灵感页“和ta聊”右上角“TA 的了解 ›”可直达）：查看每条推断及依据次数、逐条删除、关闭个性化（不再注入画像）、清空全部。接口：`GET /profile`、`POST /profile/signal|remove|settings|clear`，均需登录，按账号隔离。

## 发布

后端增量发布即可生效（无反馈数据时画像为空，旧客户端不受影响；`exploreCount` 默认会让开场推荐包含一个新方向）。小程序反馈按钮与“TA 的了解”页需随下一版提交审核。若新增“操作记录”类信息收集，提交前核对《用户隐私保护指引》是否需要补充。
