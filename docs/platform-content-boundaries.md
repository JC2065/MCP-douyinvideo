# 预期与内容边界控制

第103次：先把预期说清楚/内容边界分别默认自动，手动展开；切换只控制编辑复杂度，保留已有创作偏好和手填“必须出现/不要出现”。内容边界位于预期组下方、时长和生成设置之前。自动不是新增一次AI调用，而是使用当前偏好和所选平台默认约束。

发布平台始终可见并支持多选：抖音、视频号、小红书、快手、哔哩哔哩，初始选中抖音，至少保留一个平台。平台约束按并集合并，手工约束独立保留，不截断或覆盖。选择新平台即清除旧分镜，客户端及服务端都要求重新确认；生成服务按平台ID从可信配置重建提示词，不接受客户端注入规则正文。规则版本/平台集合附在分镜和生成请求中。

目录为utils/platform-boundaries.js（小程序可直接加载的JS）和platform-boundaries.json（服务端共享数据），有一致性测试。当前为版本化内置条目，尚未新增中台规则编辑器或自动审核判定。使用简化的创作辅助约束，不能代表平台全部规则，也不保证审核通过。AI标识涉及发布声明等动作，提示词不能代替真实发布时选择标识。
