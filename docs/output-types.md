# 生成参数与作品类型

第104次：用户确认文字/图片/视频指最终作品类型，并明确图片模型先不配置。移除预期提问中的“主要用什么画面”，把三选项放到“生成参数”标题右侧，默认视频。旧纯文字视频载荷仍兼容，但不以“文字”选项冒充文字作品。

文字模式隐藏时长和视频参数，点击生成文字先确认可能产生文本模型费用，再通过/works/text请求现有千问文本连接。返回标题与正文后显示文字结果页，可复制；从创作起点的“我的文字作品”查看最近20条。结果保存在持久卷auth/text-works.sqlite，按账号读取，不提供其他账号作品。服务端保留手机号绑定校验、32KB请求上限、单次生成并发保护、每账号30秒间隔、requestId成功重试去重与脱敏失败提示。文字模型读取已有私有千问连接，不混用灵感对话记录或热点调用场景。服务端内部文件路径和凭据不发模型或客户端。

图片模式保留选项，显示“图片模型待配置”，禁用生成按钮，不调用视频或假图片接口。后续配置真实图片模型后才能开启实际图片生成。

视频模式沿用现有Wan参数、时长、分镜审核和视频生成。切换类型清除旧分镜，防止误用旧方案。文字与图片不展示视频参数。

验证：42项客户端测试；33项隔离Python测试，覆盖文字接口手机号鉴权、账号作品隔离、持久化、错误脱敏、去重、限流及现有视频路径。原生三种模式切换与截图通过，测试未调用真实付费文字/视频模型；真实微信账号的完整文字生成仍待验。图片未配置的边界按用户要求保留。
