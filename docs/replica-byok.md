# 1:1 复刻（用户自备 Key）

用户决定（2026-10-18）：百炼 wan2.2-animate-move 成本较高（实测账单标准档 ¥0.40/秒），作为高质量 1:1 复刻提供，**由用户使用自己的 Key、自己充值**；日常低成本方案另行研究。

## 流程
爆款拆解复刻页获取参考视频 → “1:1 复刻（用自己的 Key）” → `pages/replica/index`：选择平台（阿里云百炼 / 千问AI平台）并填写 Key（可“检测”，调用 getPolicy 不扣费）→ 选人物照片 → 标准 / 高质量 → 勾选授权声明 → 确认预计费用 → 生成（3–6 分钟）→ 预览、保存到相册。

## Key 处理
- Key 只在手机本地保存（用户可选不记住/清除），每次请求随 HTTPS 发送；服务端仅在该请求内使用，不落盘、不写日志、不回显；错误信息中出现 Key 会被替换为 ***。
- 任务只保存平台任务号；查询进度需再次携带 Key，服务重启不会丢任务。
- 平台地址只允许白名单：`dashscope.aliyuncs.com`、`maas.qianwenaiapi.com`；上传与结果下载只接受 `*.aliyuncs.com`。

## 服务端（scripts/replica.py）
- `POST /replica/check`、`POST /replica/jobs`（≤9MB，含 base64 照片）、`POST /replica/status`、`GET /replica/jobs`、`GET /replica-media/<id>.mp4`（账号签名访问，资源类型 `replica`）。
- 参考视频必须属于当前账号（复用 AUTH.reference）；>30 秒自动截取前 30 秒；照片重新编码为 JPEG（去除 EXIF/位置），短边 ≥200、长宽比 ≤3:1。
- 每账号同时最多 2 个进行中任务、每日 20 个；成片固定带平台“AI 生成”水印。
- 平台错误转为中文：Key 无效、余额不足、未开通模型、内容审核、参数无效、限流。
