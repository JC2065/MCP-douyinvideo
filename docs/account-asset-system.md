# YOUAI 统一账号与资产系统

日期：2026-10-15。状态：设计交付，尚未实施统一账号迁移。承接[数据中台](backend-data-platform.md)及[模板工作流](analysis-template-workflow.md)。

## 当前实施：微信与手机号（2026-10-15）

当前只提供微信登录。小程序直接进入灵感页，从底部弹出手机号授权窗口；首次授权成功后收起窗口，后续已绑定账号无需重复授权。默认随机文字昵称和头像由服务器创建并持久化，不索取微信头像或昵称。未绑定或连接失败时保留弹窗，服务端拒绝受保护业务。管理员仍使用独立管理会话。

手机号通过微信服务端接口换取，客户端只能提交授权code。保存脱敏号码与HMAC摘要，不保存完整明文手机号；拒绝重放、伪造号码及不匹配的AppID。保留原有微信派生UUID和资源归属，尚未实施统一账号迁移。用户已确认手机号组件开通且隐私声明完成；真实手机授权仍待验收。

以下多身份、恢复邮箱、Web扫码和资产迁移属于后续设计，不是当前登录方式。

## 1. 核心决策

用户拥有一个独立的 YOUAI 账号，当前微信是唯一登录方式。登录方式、内容归属、文件存储位置分离；换手机不搬账号，换登录方式不搬文件，换服务器不改变账号和资产ID。

用户补充未来知识星球付费成员绑定：[会员与权益方案](membership-entitlements.md)。账号持有资产，外部成员关系提供资格，权益服务决定功能/额度；免费与付费共用同一账号体系，到期或解绑不删除资产。此方案为设计预留，不代表官方成员API或生产绑定已接通。

首期只做个人创作者账号与资产库，不引入团队空间、商家支付和复杂角色。普通用户从“我的 → 账号与资产”进入；管理员中台管理任务与服务状态，不使用管理员身份代替用户登录。现有管理员密码不作为用户公共密码。

## 3. 我的页面与用户流程

“我的”顶部显示头像、昵称、YOUAI账号编号和同步状态。账号编号只用于辨识，不是密码或恢复凭证。

账号与资产提供以下入口：

- 账号安全：已绑定微信、恢复邮箱、设备管理、退出当前设备、退出其他设备。
- 我的资产：作品、素材、音频、脚本/分镜、灵感/收藏、DIY模板。按项目、时间、类型、来源筛选，搜索名称，标明同步中/已同步/缺文件/待重试。
- 数据与迁移：导入本机历史、导出我的数据、迁移到另一个账号、查看迁移记录。
- 回收站：恢复内容、永久删除；明确删除的是本机索引、云端内容还是文件。

首次打开先验证微信身份，创建或读取账号档案，再展示该账号云端资产；本机旧内容单列为“待确认归属”。用户看清条数与清单后确认导入，不能把同一台手机上全部旧内容自动认领给当前微信。

换手机：登录同一微信 → 云端恢复资产索引和模板 → 按需下载文件。显示可恢复总数、完成数和失败明细，空列表不能假装同步成功。未上传的本机内容必须先在原设备同步。

Web首期通过已登录小程序扫码授权同一账号；二维码一次性、短期有效，小程序显示网站与登录设备并明确确认。恢复邮箱经验证后可用于找回；手机号已作为当前微信账号的必要授权条件。没有任何可验证的绑定方式时不能仅凭昵称或资产链接找回。

## 4. 账号与会话模型

| 实体 | 关键字段和约束 |
| --- | --- |
| users | user_id UUID、display_number唯一、display_name、status、created_at；ID一经建立不因换绑重建 |
| user_identities | identity_id、user_id、provider、issuer、subject、verified_at；unique(provider,issuer,subject)，微信issuer必须包含AppID |
| legacy_user_aliases | legacy_issuer、legacy_user_id唯一映射到canonical_user_id；只允许服务端建立 |
| sessions | session_id、user_id、client_type、device_id、token_hash、expires_at、revoked_at；设备名称不作为认证依据 |
| account_operations | 类型、发起账号、目标账号、状态、清单哈希、到期时间、幂等键、审计ID；迁移不靠客户端直接改owner |

现有users和user_identities表优先扩展，不另建一套平行账号库。当前SQL中的provider+subject唯一约束需先迁移成含issuer的唯一键；服务端验证所得身份才能入库。UnionID即使可得也不作为未经确认自动合并账号的依据。

对于已有微信用户，首次建立canonical账号时优先保留当前派生UUID作为users.id，避免已有模板与媒体归属变化；已存在其他主账号时经过明确绑定或迁移流程建立别名，不直接改写整个目录。新绑定身份只查映射，不再用其派生ID直接决定归属。

未来由统一身份服务签发会话，Python媒体服务通过可信内部鉴权校验并取得canonical_user_id；旧两小时会话在有限兼容期内只通过已核验别名解析，随后失效。不得信任公网X-User-Id或客户端提交的user_id。账号停用、解绑和敏感迁移后撤销相应会话；短期媒体签名亦须重新检查当前权限或账号撤销版本。

## 5. 资产模型与同步

| 实体 | 用途 |
| --- | --- |
| projects / project_versions | 项目、脚本、分镜与不可变历史快照 |
| assets | asset_id、owner_user_id、project_id、kind、name、version、status、source、created_at、deleted_at |
| asset_files | asset_id、file_id、sha256、size、mime、storage_provider、object_key、verified_at；不存过期签名URL当永久地址 |
| asset_relations | 原片→提取音频→文案→成片等来源关系；迁移必须包含依赖清单 |
| user_settings / templates | 账号偏好及DIY模板，沿用当前revision比较语义 |
| change_log / import_items | 增量同步、删除墓碑、逐条导入结果和去重凭据 |

元数据在PostgreSQL统一管理；媒体文件继续兼容现有磁盘和飞书归档，由存储适配器访问，未来可迁至对象存储。飞书目录是存储目的地，不是用户账号，也不是权限判断来源。普通账号不能读取平台归档凭据；导出只含本人有权导出的内容。

所有列表在服务器按canonical_user_id过滤；知道任务ID或文件哈希不代表有权限。相同sha256可复用物理文件，但每个用户拥有独立逻辑资产和授权；一个账号删除内容时，仍被其他账号引用的文件不可物理删除。

写入带Idempotency-Key及expectedVersion，服务器生成时间和归属；多端冲突保留双方版本，不静默采用最后一次写入。增量同步以游标拉取，删除保留墓碑；UI分开显示本机保存成功和云端同步成功。任务创建时固定owner及配置版本，账号迁移期间运行任务要先完成或显式取消，禁止将处理中间结果转给其他账号。

## 6. 三类迁移

### A. 本机导入与换机

扫描旧storage → 展示来源设备、资产清单和预计文件量 → 用户确认归属 → 分批上传与校验 → 服务端登记索引 → 按项回读核验 → 标记已导入。幂等键包含账号、导入批次及旧记录ID；同名不等于重复，快照与文件哈希用于识别。样例数据不自动导入真实资产库。

旧云端文件只在当前用户已有资源授权或具备可核验历史归属时建立索引；缺owner的历史文件进入待人工核验清单，不因请求携带路径就认领。导入失败保留本机原件，重试不重复建资产。

### B. 换微信、换账号与合并

仅换登录方式：从原账号发起绑定 → 新微信独立验证 → 展示绑定账号 → 双方确认 → 原账号ID及资产归属保持不变。新微信已属于另一个账号时不能直接绑定覆盖，转入合并流程。

合并/转移状态机：draft → awaiting_dual_auth → preview → confirmed → copying → verifying → committing → completed；可在提交前进入cancelled或failed，提交后只能通过补偿任务恢复。

同时证明源账号和目标账号控制权；敏感确认有效期建议10分钟，最终提交前重新验证。默认整套个人资产合并，预览列出数量、文件量、模板冲突、分享影响、运行任务与不可迁移项；默认保留源副本直到校验与确认完成，不设计“一键清空旧账号”。

源账号迁移期间冻结清单范围的新写入，检查活动任务；超时不应无限冻结，任务租约过期解锁。目标账号仍可使用，提交前重新检查其版本。先复制元数据/授权映射与依赖，再验文件，最后事务提交可见归属；大文件搬运在事务外完成，未提交的目标资产不可见。失败按清单恢复授权/可见状态，可续传，不删除源文件。

模板重名同时保留并重命名，ID冲突生成新ID并保存映射；项目引用一并更新，作品历史模板快照不改写。书签指向平台公共案例可去重，用户笔记不得丢弃。分享链接默认撤销或重新签发，不自动继承未知访问者授权。转移资源的旧媒体签名立即失效，通过撤销源授权/签名epoch实施；仍保留副本的源账号应明确保留访问权。

管理员仅处理有证据的找回申请，不得仅输入目标user_id任意搬资产。全部迁移均有审计和逐项结果；如果找不到原账号验证方式，先走受控找回，不能降低为迁移码即授权。

### C. 服务器与存储搬迁

账号ID、资产ID、文件相对键保持稳定。备份PostgreSQL、SQLite会话/模板/资源映射、归档任务状态、媒体目录及配置；密钥单独加密保管，不放用户导出包。生成版本化manifest，记录文件SHA256、大小、schema版本和依赖。

目标环境恢复 → 对齐水位并做最终增量/短维护窗口 → 校验数量与哈希 → 验证登录、跨账号拒绝、播放/下载、模板同步与归档恢复 → 切换入口 → 观察和保留旧节点。新节点写入后回退需先停写并回灌增量，不能只切DNS导致新资产丢失。服务器搬迁验收必须包含实际恢复和业务回读，不能只检查ZIP能打开。

## 7. API 草案（尚未接入）

沿用/api/v1设计；当前/youai媒体路径通过适配层兼容，不要求老客户端立即换地址。

| API | 行为 |
| --- | --- |
| GET /api/v1/me | 账号编号、绑定方式脱敏、同步水位 |
| POST /api/v1/auth/links/start、/confirm | 短期一次性身份绑定挑战；必须验证两个主体 |
| GET /api/v1/sessions；DELETE /api/v1/sessions/{id} | 查看及撤销本人设备 |
| GET /api/v1/assets | 本人分页资产库，游标与类型/项目筛选 |
| POST /api/v1/imports；GET /api/v1/imports/{id} | 本机导入预检、分项状态和重试 |
| POST /api/v1/exports；GET /api/v1/exports/{id} | 本人导出任务与短期私有下载 |
| POST /api/v1/account-migrations；POST /{id}/confirm、/cancel | 双方验证、清单确认、提交前取消；禁止任意owner修改 |
| GET /api/v1/account-migrations/{id} | 仅参与双方可看进度及各自授权范围内的明细 |
| GET /api/v1/sync/changes；POST /api/v1/sync/operations | 复用现有增量、幂等和版本冲突契约 |

认证失败401、跨账号资源统一404、版本冲突409、验证挑战过期410、限流429。现有媒体接口403先兼容，统一规范时单独测试和发布，不在设计阶段修改线上返回。

## 8. 实施顺序与验收门槛

1. 统一账号映射与档案、会话管理。保留老UUID，适配模板与媒体鉴权；验证旧数据仍可访问、同微信稳定、不同账号隔离、解绑/撤销生效。
2. 云端资产库与本机导入。先覆盖视频/音频/DIY模板，再补灵感/脚本/收藏；验证空缓存登录可列出并下载既有资产，导入中断重试无重复，缺文件不报告完成。
3. 小程序“我的”账号与资产入口、Web扫码登录、恢复邮箱。验证拒绝扫码、超时、重放、会话撤销、切换账号清空前端缓存和未提交状态。
4. 数据导出与迁移预检，再开放双账号迁移。验证无源账号授权、清单被改、目标版本变化、运行任务、文件损坏、进程崩溃、重试和补偿；确认任何失败都不提前删除源资产。

首期不同时启动两个环境的写主库；统一身份和资源归属未通过前，不上线账号合并。验收区分单元测试、开发者工具、真实云端、两部真机及正式发布，不以设计文档或模拟登录替代线上完成证明。

固定账号/资产页面与数据契约后，来源同步、任务修复、数据迁移进度等由服务端迭代；新增客户端页面、登录能力或交互仍需正常发布审核。下一次逻辑改动累计80，按仓库规则执行完整测试。
