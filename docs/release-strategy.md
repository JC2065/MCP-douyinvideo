# YOUAI 双轨发布方案

## 当前落地范围（累计 67）

手机媒体处理仍使用固定 HTTPS 域名。新增公开 GET `/client-config`，不包含密钥、用户信息或服务地址。客户端启动异步获取，4 秒超时，按后端地址缓存 1 小时，失败或不支持的 schema 保留有效缓存；缓存过期回到内置默认。每次请求上报客户端版本 1.1.0 与配置 schema 1，旧客户端不带版本头仍可用。

当前白名单仅为已有 download/transcript/audio/eraser/cover 的 maintenance 布尔值。服务端同样执行维护限制，因此旧版不能绕过。未知字段丢弃，不下发 JavaScript、页面、URL、价格、权限或新工具。配置开关只用于暂停已有服务，不用于藏匿待审功能。展示参数、模板服务等将按真实需要逐项加入协议与测试。

## 运维配置与回滚

广州部署目录 `/opt/youai/internal-api`，配置路径 `credentials/client-config.json`，通过现有只读凭据目录挂载。默认文件缺失时全部可用。

```json
{"revision":"2026-10-14.1","tools":{"transcript":{"maintenance":false},"audio":{"maintenance":false}}}
```

修改流程：保存带时间戳的旧文件副本；准备新 JSON 并校验；在同目录原子替换；读取公网 `/youai/client-config` 核对 revision；测试目标工具。回滚同样原子恢复旧文件，并赋予新 revision。服务每次读取文件，无需重启。维护状态解除后客户端缓存最多滞后一小时，重开小程序会刷新。配置不可用默认开放，仅适用于运营维护，不得作为授权、付费或隐私安全门禁。

## 发布分流

- 云端：解析器、识别模型、提示词、重试与性能。接口保持兼容，先测试，再发布与健康/业务验证，保留上一镜像与数据恢复材料。
- 客户端：页面、播放器、文件保存、微信能力、新业务。先开发和体验版验证，再合并一批提审；严重故障独立修复。暂以每周一次为计划，不承诺固定审核时长。
- 内容：未来教程与模板走受限内容接口；不能以内容接口执行新逻辑。

## 体验版、审核版、正式版

开发环境与正式环境明确区分。当前模拟器使用本机、手机使用生产；在接入独立测试环境前，体验版测试不得创建真实收费任务或污染真实业务数据。体验版只供授权成员测试，不替代面向公众的正式发布。

体验版流程：上传指定 Git commit、记录客户端版本/云端镜像/配置 revision、后台设为体验版并管理体验成员、验证完整链路。管理员操作未自动完成，不宣称已经建立体验版。

提审时冻结该 commit 并打发布标签，保持审核环境功能可见且与待发布内容一致；后续开发进入下一版本。审核通过后按平台支持的方式发布。云端回滚与客户端回滚分别记录，不能假定所有手机同时更新。

## 后续阶段及验收

1. 本次：配置协议、维护开关、缓存降级、版本上报和兼容默认，已实现。
2. 将同步 `/tools/run` 迁为统一异步任务接口；保留旧接口，先覆盖音频与转写，再迁移其他工具。状态固定 queued/running/succeeded/failed，结果固定 text/audio/video/image；进度与错误结构统一。
3. 抽出通用结果组件：文本可编辑复制、音频播放导出、视频/图片保存；不实现任意远程页面引擎。
4. 建立独立测试环境、体验版和正式版兼容矩阵；每个云端候选版本对当前正式版、下一体验版验证登录、任务、下载与资产隔离。

本次不将后续阶段描述为已完成。新业务、权限或采集变化仍需按微信当时规则评估提审。
