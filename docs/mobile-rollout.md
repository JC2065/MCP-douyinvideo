## 按顺序执行

1. 广州：复核三容器健康、迁移及 TLS；生成数据库备份并下载仓库外。已部署目录 `/opt/youai/internal-api`。
2. 纽约：通过用户在控制台提供的指纹验证 SSH；确认 CPU/内存/磁盘、80/443、证书、旧服务配置和备份。未知服务不停止。
3. 安全：微信 code 换取服务端身份，短时会话，作品/素材/任务归属检查，下载签名；密钥仅服务端保存。两个账号互相访问必须拒绝。不能用固定共享用户 ID 暴露现有内部 API。
4. 处理链：配置模型和解析服务、串行重任务、持久任务状态及失败重试。语音转写单独验收；先合成样片，再真实抖音与上传样片，付费调用前明确单次预算。
5. 临时入口：备份后新增 HTTPS 路由，不覆盖旧项目；证书校验正常，上传大小/超时/Range 下载测试通过。保留现有 DNS，确需切换再执行。
6. 小程序：环境地址区分，正式版使用 HTTPS；request/uploadFile/downloadFile 按实际请求域名配置。微信开发者工具开启合法域名校验，再手机移动网络验证。
7. 验收：三种创作入口、参考分析、确认分镜、生成、播放、保存、反馈归档、重启历史保留、两账户隔离；模型失败与额度不足可见，不把文字样片成功当作 AI 生成通过。
