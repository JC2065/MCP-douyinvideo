# 热点总结与创作入口

2026-10-16，第88次。小程序推荐区突出搜热点，展示本次页面会话最近六个去重搜索词；点击词条重新搜索当前已同步榜单。正在升温、新上榜、完整榜沿用原筛选。AI总结按当前平台从服务端真实快照取最多20个非过期话题，不接受客户端提供的新闻正文。

POST /hotspots/summary，JSON仅platform；需要微信会话及手机号授权。无数据或服务不可用返回503说明，不填充虚构热点。每账号一分钟请求间隔，相同来源快照缓存十分钟。第三方标题仅为输入数据，提示词限制忽略其中指令；保留来源及生成时间，不声称覆盖全网。

服务器凭据位于/credentials/hotspot-ai.json（宿主credentials只读挂载），含url/model/key；可由YOUAI_HOTSPOT_AI_CONFIG指定路径，环境变量YOUAI_HOTSPOT_AI_URL、YOUAI_HOTSPOT_AI_MODEL、YOUAI_HOTSPOT_AI_KEY优先覆盖。文件不进入Git、客户端或日志。生产配置北京百炼兼容接口，模型qwen3.8-max，官方说明：https://www.alibabacloud.com/help/en/model-studio/qwen3-8-max 。受控模型请求已成功；当前热榜没有非过期快照，真实热点完整总结仍待有数据后验证。

默认模板以既有六种稳定ID展示：通用结构、情绪场景、卖点表达、优惠转化、演示证据、镜头节奏；点击预览后可设默认或复制DIY。原模板与云同步兼容。工具入口仅按用户要求调整名称和排版；全网下载的实际平台范围仍取决于解析服务，图片去水印的图片处理尚未接入，原eraser处理仍为视频无水印源解析，本次没有新增图片修复能力。

## AI选题对话（第91次）

主页面热点区优先展示AI选题对话，原平台/关键词/三个榜单在“查看热点榜单”中保留。通过服务器认证且手机号已绑定后，进入灵感页自动请求推荐；十分钟内复用当前账号最近回复，防止频繁返回产生重复调用。支持多轮聊天、建议主题带入视频创作、明确确认后清空对话。

POST /topics/chat严格接收message/requestId/opening，服务端注入身份，拒绝客户端历史或userId。上下文只读取当前账号有归属的云端生成请求摘要、服务端拆解偏好和本人最近六轮对话，不上传共享本机store或本机创作偏好。无历史时冷启动；无榜单时明确是创作建议。保留每账号最近30轮，SQLite随生产持久卷保存；POST /topics/chat/clear删除本人对话，不删除作品/素材。原始会话/手机号/密钥不进入模型。

模型输出reply与1–3个title/angle主题，结构校验失败不保存伪造回复。失败保留输入并用同requestId重试；按账号幂等与限流，账号切换清除画面、忽略旧响应。连接身份服务失败时清空私密对话显示。开发工具页面预览不会跳过云端手机号权限，真机对话仍需本人完成授权。

## 关键词搜索与持续关注（第94次）

搜索不再只匹配本机榜单标题。GET /hotspots/search?q=返回当前采集热榜中的ranked与真实网页检索items两类数据；网页结果明确不是平台榜位。查询1–40字，外部检索最多2个并发、每词缓存5分钟，失败状态不补造结果。优先词条位于综合/微博/抖音/今日头条/快手之前；点词查看相关内容与平台观测。

GET/POST /hotspot-watch读取/添加本人关注，POST /hotspot-watch/remove取消；手机号鉴权与现有受保护业务一致，不接受客户端user_id。每账号最多20词，最近搜索置前；SQLite随生产卷保存。服务端独立线程每10分钟采样一次，页面打开时亦每10分钟刷新展示。保存7天观测，界面显示最近8次采样。仅监测当前来源采集的前50项，未入采集榜不代表全网无热度；来源异常记unknown而不是掉榜。不同匹配话题切换不计算伪升降，只有相同话题、两次有效快照且间隔不超过30分钟才比较榜位。

本机开发者工具私有配置urlCheck=false用于联调，发布project.config.json保持urlCheck=true；不会放开云端微信鉴权。明确的开发工具预览模式用独立preview存储，不伪造账号关注。当前微信账号经服务端核验已绑定手机号，真实会话已验证云端关注恢复；这不等价于另一个物理手机的操作验收。
