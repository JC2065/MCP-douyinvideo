# 后台拆解与视频理解摘要

第101次：用户确认“后台排队”只完成视频拆解并存入记录，不生成成片。

视频素材取得并创建拆解任务后，可选择后台排队。按钮复用当前analysisJobId，不重复创建任务，不提交视频生成；保存本机账号任务索引后进入我的拆解记录。拆解已完成时直接保存结果。素材尚未取得、任务尚未建立时按钮不可用；错误提示保留在原页。右侧“保存开始出片”仍先保存拆解，再进入现有成片沟通与分镜确认流程。

服务端线程在用户离开页面后继续执行，任务创建、阶段进度和完成/失败结果原子保存于持久卷references/jobs。完成结果可通过原有账号鉴权的reference-analyses接口恢复。重启前未完成任务显示失败并提示重新提交，不假报继续运行，不自动重发任何付费生成。

任务索引按账号保存在本机；记录页显示进行中/失败状态，前台每4秒刷新，离开后停刷新。完成结果自动存入账号本机拆解记录并移出进行中列表；服务器保留完成结果。刷新期间切换账号不会把旧账号结果写入新账号。未实现跨设备任务列表；卸载/清除本机存储后不能凭新设备自动找回任务索引。

理解摘要置于“已形成可复用的内容结构”前，只引用实际分析的时长、画幅、节奏和音轨文案。没有语音证据则明确说明，不据通用方法标签虚构视频主题。当前不包含新增多模态语义模型调用，画面主体和含义仍提示用户核对。

五档采样与自动/手动按钮显式覆盖全局88rpx最小高度，设为44rpx；默认设置区进一步压缩上下内边距。示例截图仅用于界面验证，测试后清除，不代表真实视频分析结果。
