# 创作板块隐私说明（M13）

本文件是隐私相关文案与数据处理的**唯一说明**。小程序内文案（`utils/collect-statement.js`、`utils/link-notice.js`、`utils/board-page.js`）与本文件必须逐字一致，`tests/privacy-doc.test.js` 会校验；改文案时两处一起改，并把采集声明 `VERSION` 加 1。

## 公开评论

解析抖音作品时通过 DTK 接口取最多 20 条公开热评（`scripts/top-comments.py`），按作品 ID 缓存 24 小时。只保存脱敏且不超过 80 字的文本、点赞数、回复数及是否作者回复；联系方式替换为占位符，@提及替换为「[用户]」；不保存评论者昵称、头像、账号 ID 或评论 ID。按热度（赞 + 3×回复）排序并标注共识/讨论/长尾，最多 20 条进入拆解提示词（`post.topComments`），拆解卡先展示 3 条、可展开。接口失败时返回空列表，不影响拆解。DTK 上游的缓存策略需单独管理。

## 小程序内首次使用告知（已实现：pages/video 拆解页首次出现拆解会话时显示，utils/board-page.js `youai-board-privacy-v1`）

> 为了改进拆解与创作质量，你在创作板块中的会话内容（问答、纠正、拆解方案、产出路线）与作品数据会与账号关联上传，用于改进服务和全站统计；后台截图只用于识别数字，识别后不保存。所有问题都可以不回答。

## 登录时的用户信息采集声明（已实现：首页登录弹窗，utils/collect-statement.js，当前 VERSION=2，勾选同意后才能手机号验证或生成体验账号）

1. 手机号：用于账号注册登录、账号安全，以及在需要时与你联系、核对问题来源。完整号码保存在我们的服务器上，并同步到我们内部使用的飞书多维表格，仅限运营人员查看。
2. 创作内容：你在拆解与创作中的问答、对 AI 理解的纠正、拆解方案、产出路线、灵感碎片和作品数据，会与账号关联保存，并同步到我们内部使用的飞书多维表格长期归档，用于提供服务、改进拆解质量和全站统计。
3. 截图与语音：创作者后台截图只用于识别数字，识别后不保存；语音只用于转成文字，转写后即删除。
4. 公开内容：解析作品链接时读取作品公开信息和公开评论文字，并在内部保存封面、4 张截图和低清视频副本，仅用于核对与归档，不对外提供下载；不保存评论者的昵称、头像和账号。
5. 你可以不回答任何问题、不回传数据；不登录也可以浏览和体验。

声明内容变化时把 `VERSION` 加 1，所有用户会在下次登录时重新勾选（v1→v2 于 2026-10-20：新增完整手机号、同步飞书、内部保存截图与低清副本）。

## 服务器与飞书上实际保存了什么（对应声明第 1、2、4 条）

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 完整手机号 | 服务器 `auth.sqlite` 表 `phones`（`scripts/wechat-auth.py`，`AUTH.phone(user)`）；飞书「用户」表 | 只有 v2 之后新绑定或重新授权的用户才有完整号码，老用户只有脱敏号 |
| 拆解会话、方案、作品、数据回流 | 服务器 `board.sqlite`；飞书「理解卡/拆解库/方法卡/作品库/数据回流」及「拆解库·方案名·ID后4位」「拆解库·仅本次调整」 | 由 `scripts/asset-ledger.py` 先写 `/data/assets/ledger/ledger.sqlite` 发件箱，再后台投递飞书 |
| 封面、4 张截图（封面+中段两张+结尾）、360p 低清视频 | 服务器 `/data/assets/ledger/media/`；飞书「素材库」附件 | 仅内部核对与归档，不对外提供下载 |
| 后台截图、语音 | 不保存 | 截图识别数字后丢弃；语音转写后删除 |
| 评论者身份 | 不保存 | 见「公开评论」 |

飞书 base 属管理组织，含完整手机号，**分享权限只能给运营人员**；人工列（我的评分/我的标签/运营备注/优化备注/用过次数/效果评价）系统不写。停用同步：去掉 `video-server.py` 里的 `LEDGER.start()`（发件箱仍记录）。

## 链接使用说明（粘贴链接时，utils/link-notice.js）

> 链接解析仅用于你个人学习、分析爆款创作手法，有AI不对外提供原视频的下载或二次分发（为方便核对，会在内部保存截图和低清副本）。请尊重原作者的著作权与肖像权，创作时请改写文案、使用自己的素材；因不当使用产生的法律责任由使用者自行承担。你也可以直接上传有权使用的视频。

免责说明与内容识别说明合并在一个弹窗里，点「我知道了，开始识别」即开始识别，不再二次确认；「1 小时内不再提示」由用户勾选，过期后重新确认。

## 需在微信公众平台“用户隐私保护指引”补充/核对的条目（需管理员登录后台操作，Claude 无法代为提交）

| 信息/权限 | 用途填写建议 |
| --- | --- |
| 选中的照片或视频信息 | 上传原视频用于内容拆解；上传后台截图用于识别作品数据（截图识别后不保存）；选择画面视频用于套版成片 |
| 相册（仅写入） | 保存生成或合成的视频、封面到相册 |
| 订阅消息 | 作品发布第 1、3 天提醒回传数据（用户在小程序内同意后才发送） |
| 用户输入的内容（文本） | 拆解问答、纠正、拆解方案和需求描述，与账号关联，用于改进服务与全站统计 |
| 麦克风（录音） | “我想记”按住说话记录灵感碎片：录音仅用于转成文字，转写后音频即删除，只保存文字（docs/idea-box-plan.md） |
| 选中的照片或视频信息（灵感碎片） | “我想记”截图碎片：从相册、拍照或微信聊天中选择截图，识别其中文字并保存截图，用户可随时删除 |
| 微信聊天中的文件 | “聊天里选”截图碎片，仅读取用户主动选择的图片 |
| 用户输入的内容（灵感碎片） | 文字和链接碎片保存在账号碎片箱，选题助手 TA 会读取未使用的碎片为用户推荐选题 |
| 剪切板 | 拆解页「点这里粘贴链接」读取剪切板中的作品链接（`wx.getClipboardData`，仅用户点击时读取），用于开始解析 |
| 手机号 | 账号注册登录与安全；完整号码保存在服务器并同步到内部飞书多维表格，仅运营人员查看，用于联系与核对问题来源 |
| 第三方存储（飞书多维表格） | 创作内容、拆解方案、作品数据及素材截图/低清副本同步到内部飞书多维表格长期归档（见上文「服务器与飞书上实际保存了什么」） |

订阅消息模板需在小程序后台“订阅消息”中申请（建议关键词：作品名称 thing1、提醒内容 thing2），把模板 ID 填到管理中台“创作板块参数 → 订阅消息模板ID”。未填写时不会发送任何提醒。
