# YOUAI 下一轮迭代：中台管理后台

2026-10-16：新增[六板块中台与三阶段个人流程设计](workflow-platform-design.md)，含可交互预览、网页/小程序共享定义、默认/个人流程、Skill沟通和飞书数据积累。本页保留早期实施说明；新流程系统尚未部署。

## 本轮目标

用浏览器管理已部署的小程序服务，减少手工改服务器配置。当前云端有数据/处理API与维护开关，还没有完整管理界面。当前小程序版本固定为兼容基线；新迭代优先走管理后台及兼容API，不混入小程序视觉大改。

## 第一阶段范围与验收

| 模块 | 首批功能 | 验收 |
| --- | --- | --- |
| 身份与审计 | 独立管理员登录、会话过期、操作审计、敏感值脱敏 | 普通小程序会话不能访问管理接口；未登录不可读写；修改可追踪 |
| 热点内容 | 查看来源更新时间、成功/空结果/失败状态；单话题重试 | 用真实来源显示内容，不能把索引摘录标成全文；并发仍有界 |
| 任务错误 | 查看生成/解析/转写任务状态和失败原因 | 不显示密钥/签名URL；不会自动重复付费任务 |
| 工具开关 | 暂停/恢复已有5项工具 | 管理操作只修改维护状态，服务端与客户端兼容 |
| 配置版本 | 校验、预览差异、发布、回滚 | 原子写入、版本冲突保护、审计记录；旧客户端继续工作 |

第一阶段之后再接入AI参数/提示词模板和资产归档补偿。不是任意远程代码执行或绕过客户端发布。

## 实现边界与顺序

1. 先做独立管理员权限和只读总览；管理服务不沿用普通微信用户权限。
2. 使用固定字段API接入现有状态，明确读取失败/无数据；不使用假运营数据。
3. 增加工具维护状态及版本化发布、回滚；管理写入使用专用配置目录，不开放整个凭据目录写权限。
4. 热点重试保留现有并发/缓存约束；付费任务重试必须显示费用风险并由管理员明确触发。
5. 以当前小程序接口做兼容验证，再部署管理后台。独立测试环境仍是待办。

入口为小程序“我的 → 管理中台”（原生页面）及 `https://api.onesvips.top/youai/admin/` 手机网页。使用已有HTTPS请求域名，不依赖web-view。新增原生管理能力需随新版小程序正常提交审核；之后维护开关、热点检索、版本发布和回滚由云端执行，客户端无需为这些数据变化反复提交代码。

凭据由 `scripts/admin-bootstrap.py --directory <仓库外私有目录>` 生成；仅把admin-auth.json密码哈希放到云端只读credentials目录，明文admin-login.txt只留管理员本机。会话独立于微信，1小时到期、退出撤销、服务重启全部失效；客户端仅内存保存，页面退出清除。管理请求不使用Cookie、无CORS、浏览器Origin校验，因此不存在Cookie跨站写入。支持最近50个配置版本与100条审计查询。

工具状态发布原子替换 `/data/admin/client-config.json`，发布前显示差异并确认；expectedRevision冲突返回409，回滚新建版本而非覆盖历史。首次部署从旧credentials/client-config.json迁移，不能重置已暂停工具。专用目录写入，不给credentials写权限。

第一版任务总览仅覆盖当前服务进程中的视频生成与内容分析（最近50项），重启后没有历史记录；同步工具提取任务尚未纳入。错误只给脱敏失败提示，详细原因仍需查看受控日志。没有付费任务自动重试。AI模型参数、提示词、归档补偿和完整历史任务查询属于后续扩展。
