# 点子变视频：本机体验

进入「灵感 → 把点子做成视频」或「创作 → 一个点子，一条视频」。创作起点支持点子、抖音分享链接和 YOUAI 模板口令；模板口令需要补充本次主题。下一步只确认内容目标、主要画面形式和时长，成片时长可在 2–30 秒间拖动，也可选择“智能”并把 `durationMode=smart` 与预计秒数交给生成服务。创作档案会自动带入默认值，本次明确输入优先。提交任务时保留来源类型和原始输入，生成结束后播放 MP4，点击保存到相册。

当前仓库自带的本机服务仍只会真实合成文字短片，采访使用规则，文字使用用户原文，不是 AI 模型生成。它支持无声纯文字、360×640、24fps 和 2–30 秒时长；风格改变背景与文字配色。有轻微画面运动，不使用第三方视频。新工作流已经输出统一的来源、内容目标、画面形式和时长模式字段。抖音链接粘贴后会请求 `POST /references/read`；本机服务展开短链，确认最终视频 ID 并读取页面标题或描述，成功后返回 `status=read`，否则界面阻止继续。这个成功状态只证明生成服务能够访问并识别该视频页面，视频画面与文案的 AI 语义分析仍需后续生成服务处理；AI 画面、配音和配乐也不能仅因入口可选就标记为已联调完成。

## 启动

1. Python 安装 `pillow imageio-ffmpeg`。
2. 执行 `python scripts/video-server.py`，保持服务运行。默认仅监听本机 `127.0.0.1:8765`。
3. 运行 `node scripts/configure-local-video.cjs`，再在微信开发者工具重新编译。脚本仅关闭本地私有设置中的合法域名校验，不修改发布配置。
4. 在模拟器体验生成和播放。相册保存必须在真机验证：真机需要另行部署可访问的 HTTPS 服务、配置合法 request/download 域名并修改 `utils/video-service.js`。本机地址不能在手机上使用。

中文字体默认使用 Windows 微软雅黑；其他环境通过 `YOUAI_VIDEO_FONT` 指定字体文件。视频生成在系统临时目录 `youai-generated-videos`，任务状态存在内存；服务重启后已有视频仍可按历史链接读取，但未完成任务状态不恢复。不要直接把本地服务暴露公网，生产需补鉴权、存储、配额与任务队列。

验证：`node --test tests/*.test.js`；`python scripts/test-video-server.py` 会实际合成并完整解码一段 MP4。无服务时显示连接错误，可重试；保存权限被拒绝时可打开设置。最近 20 条结果保存在小程序本机，与已有文本作品分开。

点击回归：开启开发者工具自动化端口及本机合成服务，设置 `YOUAI_AUTOMATOR_MODULE` 指向 miniprogram-automator 后运行 `node scripts/video-click-smoke.cjs`。测试真实输入、点击首按钮、跳过全部问题及 MP4 结果，不模拟网络返回，会新增一条测试视频历史记录。会切换到新的视频页面；运行前先保存当前编辑内容。
