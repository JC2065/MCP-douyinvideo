# 统一返回导航

全部主包、分包页面使用 `components/app-navigation`，替代原生小箭头。返回能力有两个入口：

1. **顶部固定返回按钮**：箭头 + 返回文字，点击区域 88×48px，按压变色；根据状态栏和微信胶囊位置预留空间。
2. **悬浮返回球**（2026-10-09 新增）：60×60px 玻璃圆形按钮，初始在屏幕左侧约 55% 高度处，**可全屏拖拽**（导航栏以下区域），松手时按球心位置决定：**左右各 1/7 屏宽的边缘区内**自动吸附到对应边缘（8px 边距），**中间 5/7 区域悬停在松手位置**不吸附（2026-10-09 应用户要求从「总是吸附最近边缘」改为分区吸附，方便放在任意顺手的横向位置）；按压缩放反馈，拖动后 350ms 内的抬起不触发返回（防误触）。实现用 movable-area + movable-view，容器 `pointer-events:none`、球体 `pointer-events:auto`，不遮挡页面交互。**位置记忆**：拖动过程中持续把位置写入本地存储 `youai-nav-ball`（`{x,y}`，150ms 节流），不依赖 change 事件的 source 值或 touchend 是否触发（模拟器拖拽的 change source 为空字符串、合成触摸可能不触发 touchend，此前按 source==='touch' 过滤导致拖拽位置完全不保存，已修复）；松手吸附边缘后再存一次吸附位置。所有页面的悬浮球启动时读取并恢复同一位置（超出当前屏幕时自动钳制），方便单手操作。垂直拖动超过 6px 后 400ms 内的抬起不触发返回（防拖动误触返回）。

首页仅在内部二级视图显示返回，继续使用原有 close 逻辑以保留编辑上下文。有历史页面时返回一层；从独立入口打开时回首页。导航进行中忽略重复点击。未添加自定义侧滑手势，避免与横向选项和视频操作冲突。

**已知坑**：movable-area 默认尺寸仅 10×10px，必须用显式 width/height（组件内联 style 按窗口尺寸计算 areaH），否则球会被钳制在角落。

验证：`node --test tests/*.test.js`；微信编译器检查 WXML/WXSS；开发者工具自动化运行 `scripts/navigation-smoke.cjs`，覆盖 9 个二级页面的按钮尺寸与返回目标（顶部按钮与悬浮球各断言存在，video 页用悬浮球返回）。
