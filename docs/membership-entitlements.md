# 知识星球绑定与会员权益方案

日期：2026-10-15。状态：设计预留，尚未实现绑定、权益校验或自动同步；尚未向任何用户发放新权益。与[统一账号与资产方案](account-asset-system.md)配套。

## 1. 产品决定

YOUAI账号持有资产；知识星球成员关系提供会员资格；服务端权益决定可用功能和额度。三者分开，不能直接在users表写一个永久isVip。

首期两档：免费用户、星球会员。后者默认要求目标星球中已核验的有效付费资格；赠送、试用、管理员/嘉宾等单独记录，除非明确配置，不自动认作付费用户。管理员账号也不因管理身份自动获得用户付费额度。

截图显示“郑州 AI 万人交流”、展示星球号93302860，可作为待配置的目标星球。截图中的“服务至2027/9/12”不作为每位成员的到期日，展示星球号也不假设等于接口内部group_id。目标星球及核验字段上线前从真实后台核对。

## 2. 官方能力核对与首期接法

本次查询未找到足以承诺通用第三方登录、成员API或退款Webhook的官方接入文档，不代表官方一定不提供；自动接入须后续取得明确授权与接口契约。第三方逆向SDK和浏览器Cookie不能作为生产身份来源，不收集用户知识星球密码。

官方[常见问题](https://help-docs.zsxq.com/faq/faqs.html)说明可从成员信息查看加入和到期时间；[续期与退款说明](https://doc.zsxq.com/zsxq-faq.html)说明到期未续费可能仍能看旧内容，续期退款会影响有效期。因此不能只用“在成员列表里”判断有效付费权益。

官方[付费星友直播教程](https://doc.zsxq.com/planet-video-live-guide.html)提供特定场景的成员列表导出，但不能据此假定文件包含通用成员ID、准确付费状态和到期字段；其中OpenID也不能与本小程序OpenID直接等同。必须拿实际文件确认字段和用途后才开发导入。

首期采用管理员核验：用户提交绑定申请和一次性账号校验码 → 通过已验证属于该成员的星球内渠道确认校验码 → 管理员核对目标星球、成员标识、资格来源及个人到期日 → 录入有期限授权。缺少稳定成员标识或无法证明成员控制权时保持待核验，不凭昵称、头像、截图或任意兑换码直接升级。禁止自动向星球成员发送消息。

管理员从“管理中台 → 会员与权益”查看申请、核验记录、有效期、续期、撤销与批量导入预检。人工导入与自动适配器最后写入同一来源记录，避免以后换接法改客户端。

## 3. 用户界面

“我的”显示免费/星球会员、有效期和最近核验时间。点击“会员与绑定”进入：

1. 绑定知识星球：选择已配置目标星球，生成一次性随机挑战；仅当前登录用户可查看。
2. 查看申请状态：待核验、核验中、已绑定、信息不符、已过期；提示补充动作，不能等待无反馈。
3. 我的权益：明确功能、周期额度、已用额度、重置时间；AI费用是否另计单列，不把会员解释为无限付费模型调用。
4. 续期后申请更新、解绑、申诉。解绑不删除账号资产，重新绑定不重置已用额度。

上线初期该页面只做已购成员身份核验和权益展示。未审核的平台购买、外链跳转、二维码导流或支付交互不随本方案自动上线；若需新增购买路径，在实现时核对当时微信规则并正常提交审核。中台只能调整已实现且已审查能力的权益配置，不可用会员开关加载任意客户端代码。

## 4. 模型与服务端判定

| 实体 | 关键内容 |
| --- | --- |
| membership_bindings | binding_id、user_id、provider=zsxq、verified_group_id、member_subject、status、verified_at；同一星球成员同时只绑定一个有效YOUAI账号 |
| membership_evidence | 加入来源paid/gift/trial/unknown、成员状态、个人valid_from/valid_until、verified_until、核验方式manual/authorized_api、核验人、证据摘要、source_version；最少化保留证据 |
| entitlement_grants | grant_id、user_id、source_binding_id、plan_version、features、限额、valid_from、valid_until、status；可撤销、可追溯 |
| usage_ledger | user_id、feature、周期、任务ID、reserved/consumed/released、幂等键；服务端原子扣减 |
| membership_events | provider、group、事件/导入ID、source_version、received_at、结果；重复事件不重复授予，旧事件不复活已撤销权益 |

权益生效必须同时满足：绑定归属已验证、来源符合套餐条件、未撤销、开始时间≤服务器当前时间<min(成员有效期,授权有效期,核验有效期)。未知个人到期日不得发永久会员，可人工批准短期试用并明确标记试用。所有时间存UTC，界面按用户时区展示。

客户端GET /api/v1/me/entitlements只展示结果；每次受限工具创建、云端存储新增和额度消耗均在服务器重新校验，不能信任客户端会员标签或本机时钟。后台异步任务在创建时锁定权益/配置版本并预留额度；同一幂等任务只扣一次。到期前已成功创建的任务可按原授权完成；失败释放预留额度；结果读取不重新收费。

套餐候选：免费档保留基础创作、本人资产访问与导出；会员增加更高处理额度、更多高级模板或批量能力。具体额度与功能须按成本和现有已审查能力确定，当前不设价格、不启用限额、不削减已承诺能力。付费AI另设预算与确认机制，会员状态不能替代用户付费调用授权。

## 5. 有效期、退款与故障

状态流：unbound → pending → active；active可转expired、revoked或needs_review。身份绑定状态和权益状态分别存储：绑定仍在不等于权益有效。

- 续期：经核验写入新来源版本，更新有效期；不叠加重复导入，也不因重新绑定重发已用额度。
- 退款/移除：确认来源后撤销对应授权；续期退款只恢复此前仍有效期间，不能简单把整个账号永久禁用。已确认撤销优先于缓存。
- 同步失败：显示最近成功核验时间，不将超时当退款，也不无限延长权益。人工首期核验有效期建议最长7天且不得超过成员实际到期日；超期进入needs_review，暂停新增付费任务，继续本人资产访问与导出。该7天为YOUAI建议策略，不是星球规则或实时退款保证。
- 自动化就绪后：在授权、频控允许时建议每10分钟对账，具体周期以官方限制为准；区分partial与complete快照，部分或失败名单缺人不能直接撤销。即使完整名单缺失也应按明确移除信号或复核策略处理。
- 人工核验有退款发现延迟，后台清楚展示未复核记录；不能向用户承诺实时自动扣回资格。保留处理原因和申诉入口。

## 6. 资产、迁移与权益分离

会员过期、退款或解绑后，已有作品、素材、脚本和DIY模板继续归本人；基础查看、下载和数据导出不因会员失效被锁。超配额先停止新增占用并提示处理，不自动删除已有文件；实际保留期限另行明确，不能暗中改变。

账号合并不自动复制付费资格或叠加额度。迁移清单把资产与会员来源分别列出；知识星球成员只能通过重新验证绑定到目标账号，原绑定及相关授权撤销，历史使用额度随来源保留。相同付费身份不能同时为多个账号领取权益。

迁移/换绑需将来源级绑定和额度变更原子提交；并发绑定唯一约束，重放/取消/断点重试均不能生成第二份授权。管理员特殊赠送必须是独立、有期限、带理由的grant，不能伪装成已付费星球成员。

## 7. API与中台预留（未实现）

- POST /api/v1/membership-bindings/start：建立与当前账号关联的一次性挑战，短期有效、限流。
- GET /api/v1/membership-bindings/me：本人绑定与核验状态，成员信息脱敏。
- POST /api/v1/membership-bindings/{id}/review-request：续期/复核申请，不由用户直接设置paid或到期日。
- DELETE /api/v1/membership-bindings/{id}：本人解绑，撤销相关授权但不删资产。
- GET /api/v1/me/entitlements：套餐、功能、有效期、用量和核验状态。
- 管理中台review/revoke/import-preview/import-commit：独立管理员鉴权、版本冲突、批次幂等与审计；不得接受客户端伪造来源。

导入文件需限制大小/行数、验证结构、先预览差异再提交；输出错误不泄露完整成员名册。未来Webhook仅在官方支持时实现，必须验证签名、时效和重放，事件落库后异步处理。平台密钥在仓库外，不写入小程序或用户导出包。

## 8. 实施与验收

先实施统一账号和资产列表，再加入权益模型及后台人工核验，最后按取得的官方能力接自动同步。当前文档不将会员接入或账号系统报告为上线完成。

必验：非付费成员不能升级；到期不删资产；退款、续期退款和重复导入计算正确；未知到期不授永久权益；挑战重放/超时/昵称冒认被拒；同成员并发绑定只成功一次；旧同步事件不复活退款资格；部分名单不误撤销；网络故障不扩大授权；跨账号请求被拒；并发任务不超额；迁移不复制会员/额度；本人历史结果与导出仍可用。
