# 模型与技能配置（演示）

用户可选大模型并逐功能配置 skill。演示阶段仅本机存储（`youai-ai-config-v1`），不发起网络请求；API Key 等敏感信息存本机，正式接入后必须迁移到服务端托管。

## 数据层 `utils/ai-config.js`

- `models`：六个预置模型（DeepSeek / 通义千问 / 豆包 / Kimi / 智谱 GLM / 文心一言），含厂商与适用场景说明。
- `scenes`：五个功能场景——AI 找热点、视频脚本、每日一拆、文案提取、灵感扩写。
- 状态结构：`{defaultModel, keys:{模型id:Key}, custom:[最多3个自定义模型], scenes:{场景id:{enabled,model,prompt}}}`。
- 生效规则 `resolve(state, sceneId)`：**场景覆盖优先，其次全局默认**；`model:''` 表示跟随全局；场景可整体停用（入口保留，调用时提示先启用）。
- `normalize` 兼容损坏数据：未知默认模型回退 DeepSeek、未知场景模型回退跟随全局、Key≤200 字、提示词≤500 字、自定义模型最多 3 个；删除自定义模型后其引用自动回退全局。

## 页面 `pages/ai/index`（我的 → 模型与技能）

1. 默认模型：chips 单选（含自定义模型），下方显示厂商与特点说明。
2. 模型测评与免费信息（`utils/model-insights.js` 静态策展，2026-10 整理）：每模型一张卡——综合评分（按 2026 公开测评梯队排序，DeepSeek 95 居首）、梯队徽章、免费政策双标签（网页/App 免费 + API 免费额度）、一句话点评、擅长场景、「设为默认」快捷键。演示参考、非实时榜单，免费政策以官网为准。
3. 模型钥匙：每个预置模型一个 password 输入框，即输即存。
4. 自定义模型：名称/接口地址/模型名/Key，最多 3 个，可删除。
5. 功能场景：每场景一张卡——启用开关、模型 chips（跟随全局 + 全部模型）、自定义提示词（留空用默认）、工具包勾选（见下），底部实时显示「生效：模型 · 来源 · 提示词 · N 个工具包」。
6. MCPB 工具包：`.mcpb` 工具包管理——**链接安装**（粘贴 https://…/x.mcpb，取文件名做名称）或**从聊天选择 .mcpb 文件**（wx.chooseMessageFile）；每包可全局启停/删除，最多 5 个。演示阶段只保存清单元数据（名称/来源/开关），不真实下载或解析包内容（版本/作者/工具列表显示「待解析」）。
7. 保存配置 / 恢复默认（showModal 确认，不影响创作档案与作品）。

## MCPB 生效语义

- `state.bundles`：全局工具包清单，`enabled` 为全局总开关。
- 场景未单独勾选（`scenes[x].bundles` 不存在）：跟随「全部已启用」工具包。
- 场景勾选后（显式数组）：按场景清单生效，但**全局停用的包始终排除**；删除包时各场景引用同步清除。
- `resolve()` 返回 `bundles`（生效清单）与 `bundlesCustomized`（是否场景勾选）。
- 页面注意：WXML 不支持 `.some()` 等函数调用，勾选态在 `refresh()` 预计算为 `bundleState` 映射；新增包 id 用 `Date.now()+随机后缀`（同毫秒连续添加会撞 id，已修复）。
