# 内联分镜与成片发布

第105次。移除“成片计划”展示，流程编号统一为1/3内容拆解、2/3创造成片、3/3成片发布。视频/文字生成成功、重开历史作品后显示成品发布区；图片仍按用户指示待配置。

## 分镜

分镜草案位于时长下方、生成参数上方。默认自动显示开场/展开/收束三段时间轴，手动可编辑每段文案与画面。时长变化重算三段起止时间；手动文案保留，状态回到待确认。显式拖动时长优先于点子中的“30秒”等字样；智能时长继续使用已有推断规则。当前仍为三段结构，不意味着已实现随时长增加镜头数或新的AI分镜规划器。

确认生成会重新校验当前方案并要求明确确认模型费用，随后提交已批准快照。生成载荷若时长与批准分镜结束时间不同则拒绝旧方案。原有全页分镜处理保留为兼容路径，主要界面不再要求先跳到另一页。

## 成品与发布准备

成品分内容、标题、封面：视频可播放/保存，文字可查看/复制；标题可编辑，封面从相册选择并可保存到相册。标题、封面路径、所选平台按本机账号及作品ID保存最近30份草稿。封面当前为本机路径，临时文件过期后需重新选图；尚未上传为云端封面资产。

发布作品可多选平台，每个平台有独立准备入口，复制标题及文字正文，提示在目标平台创作页完成上传。复制成功、保存素材和实际发布状态分开，不报告“已发布”。没有将作品发送至任何平台。

## App直跳待接入

当前没有任意目标平台App的已验证开放能力或可用跳转配置，所以入口明确标注为“准备在…发布”，而非假装已经打开App。不填造第三方AppID，不使用未知URL Scheme，不把复制文案算作跳转成功。此项未满足用户期望的各平台直跳，需平台开放能力和可验证接入条件后继续实现、真机核验。
