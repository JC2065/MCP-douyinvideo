# 热点升温功能方案

这块首先回答“哪些话题正在升温”，再支持选择话题进入创作。原来的200条混排只提供结果，没有变化依据；标题搜索和重复通用建议不能帮助判断机会。

## 功能顺序

1. 默认“正在升温”：仅展示同平台最新成功采集中榜内位置上升的话题，按上升位数降序，再按当前位置排列。跨平台不计算热度分数。
2. “新上榜”：前一轮采集没有、最新一轮进入采集范围的话题，单独展示，不能等同刚发生的新事件。
3. “完整榜”：保留全部来源原返回顺序对应序号，包含明确标注的缓存内容。
4. 搜索匹配当前同步标题；保留平台筛选。首页先展示12条，完整列表在热点详情页浏览。
5. 卡片显示“↑上升8位 / 新入采集榜”、平台、当前位置和比较间隔。点击详情查看最近一小时成功采集的位置记录，复制来源、保存灵感或进入创作。

## 数据与真实边界

每源保存最近6轮成功快照，并记录真实采集时间。比较最新两次成功快照；间隔不超过30分钟才能进入升温/新入榜。失败不会生成一轮成功历史，缓存内容不进入升温。初次没有上一轮数据时提示正在积累数据，不能虚构趋势。

“升温”仅表示采集榜内位置上升，不代表播放量、互动量增长或预测爆款。源站推荐位、标题变更可能影响序号；新上榜准确称为“新入采集榜”。超过30分钟的成功间隔不推断即时趋势。详细采集状态收进详情，首页只保留更新时间和异常来源，减少长时间戳干扰。

## 界面设计

延续现有YOUAI蓝色与半透明底色，不增加装饰图。蓝#0868df用于当前筛选；深色#20314a用于标题；绿#127d5b用于上升证据；橙#a66514用于新入榜；灰#66758a用于更新时间；白#ffffff用于内容底。

系统字体，话题标题26rpx/650，变化数字30rpx/700，证据文字22rpx。左对齐；变化幅度放在话题旁，平台和前后位置放下一行。卡片只保留“看变化”和“用话题创作”，来源与保存收进详情。按功能层级分配空间，不再重复“结合自己的观察创作”。
