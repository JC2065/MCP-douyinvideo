# 工具接口配置

入口：“我的” → “更多设置” → “工具接口管理”。首页六个创作工具进入 `pages/creation-tool/` 执行任务；接口管理页只负责易失效服务和未来个人接口配置。

六个工具保留平台公共接口和个人配置模型。公共配置由 `utils/tool-interfaces.js` 的冻结清单维护，用户页面只读，个人存储不能覆盖公共服务标识或策略。视频下载 / 参考解析已登记平台公共服务 `youai-reference-parser-v1`，密钥只在视频服务进程中注入，不放入小程序。当前可执行工作台的五个媒体工具统一依赖该解析服务，再由 YOUAI 视频服务完成转写、音频和封面处理；提词器不依赖接口。其余个人工具接口仍是已保存的配置资产，在各自协议确定前不会被工作台静默调用。

个人配置按工具分别保存 HTTPS 地址、GET/POST 请求方式及可选 Bearer Token。保存校验格式，不发请求，也不证明接口可连通。切回公共接口保留已保存的个人配置；清除只清除当前工具并恢复公共来源。表单令牌遮蔽，停用认证后清除令牌；令牌保存在本机小程序存储，不是服务端密钥库。

当前项目没有账号登录，个人配置的范围是本机存储，不具备跨账号隔离。商家与创作者只是业务功能模式，两种模式共用本机个人配置，均不能编辑公共配置，也不获得管理员权限。客户端只读与校验不是服务端安全边界。

接入账号服务时必须由服务端根据已验证会话确定用户身份，按用户归属读写个人配置；公共配置的修改必须另行校验平台管理员权限，不能使用客户端传入的角色。公共工具调用由服务端保管凭据并校验会话、工具启用状态与使用权限。个人接口请求须在协议、合法域名、请求与返回字段约定确定后实现；当前工作台不会自动把素材或令牌发送到非“视频下载 / 参考解析”的个人配置地址。
