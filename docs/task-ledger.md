### 用户确认的目标

把参考视频工作流从“读取网页标题后直接文生视频”升级为可复用、可解释、可恢复的生产链：真实素材获取与授权 → 镜头、字幕、画面和声音分析 → 可审核故事板 → 逐镜头生成 → 配音、字幕、音乐与拼接 → 成片、成本和用户反馈沉淀。

资源利用原则：原片按哈希去重；分析只做一次；镜头作为最小复用单位；生成过程保存资产血缘；失败只重做局部；长期保留授权、分析、故事板、采用资产、提示词参数、反馈和成本；临时帧、失败低质候选和过期地址按周期清理。

### 已确认的产品规则

1. 明确区分“链接已识别”“视频已获取”“视频已分析”，不得用网页元数据冒充视频理解。
2. 参考方式分为内容结构、视觉风格、同题改编；默认内容结构。
3. 生成前展示可编辑故事板、镜头数、实际参考证据和预计付费任务。
4. 普通验证使用 Mock Provider；真实付费任务需由功能验证需要和用户授权共同触发。
5. 标准30秒720P成片按约 ¥18–25 预算，任务应记录预估和实际成本。
6. 用户可以查看实际提交给模型的提示词、参数、模型和任务状态。
7. 用户反馈必须显式、可查看、可修改、可删除，不暗中形成不可解释画像。
