# 内容先行的文字、图片、视频创作

第132次：先理解素材，再推荐表达方向。选项用于帮用户作决定；用户本次自由填写的创作要求优先于档案风格。模型连接、实际支持的画幅与时长、账号权限仍按真实能力校验。

## 创作链路

1. 取得并验证参考视频文件，按选择的密度抽帧与转写。输入框失焦且链接未变时，不重新解析；素材改变后清除旧识别补充与推荐，旧请求迟到不覆盖新素材。
2. 经独立 AI 场景 `reference_understanding` 结合最多12张分布于视频全程的代表帧和实际转写，识别内容概述、带时间/语音依据的事实、内容段落及不确定项。不是逐帧识别，未覆盖画面不推断。采样时间、语音引用和建议对应的事实下标由服务端校验。
3. 用户核对识别结果，可写补充或纠正。识别失败不会用亮度、切镜和网页标题伪装成语义理解；提供重试入口，或由用户补充内容后继续。
4. 分别推荐文字、图片、视频的目标、受众、开头、语气和结尾，并说明原因。建议默认不覆盖现有输入，用户可逐条采用；表达字段可自由填写。参考媒体方式仍对应真实视频/帧/结构通道。
5. `creativeIntent`（本次创作要求）、`referenceNotes`（识别纠正）进入三类产物。文字与视频保留素材识别，推荐和不确定项不当作素材事实。视频分镜可按实际识别段落组织（1–12段），不再要求3段；视频硬件/模型时长仍为现有2–30秒。
6. 图片走独立异步任务：提交→查询→下载并保存本机服务器PNG→结果预览、保存相册、发布草稿。图片作为创作资产按账号重新打开，并进入日历统计；生成中/失败状态可查看。

## 管理配置

- 网页管理中台“作品拆解”新增“参考视频内容理解”场景。默认模型 `qwen3-vl-plus`，使用已有 `qwen-domestic` 连接，可独立改成支持图片输入的连接/模型；模型是否开通需实际环境确认。旧配置缺失该场景时自动补齐，不覆盖其他场景。
- “创作工具”中的图片连接使用既有 `image-gen` 密钥、图片根地址和模型。当前实现阿里云 `wan2.6-t2i` 异步协议；其他模型明确提示暂不支持，不能通过更换模型ID自动取得适配能力。
- 图片可设为创作档案默认产物，并有独立个人表达偏好。技术画幅包括按素材推荐、1:1、3:4、4:3、9:16、16:9，每次明确生成1张。
- 内容识别和图片生成均在调用前向用户说明可能产生费用并确认；测试均使用mock。不要在开发者工具用真实账号点击确认来验证。

## 接口与存储

- `POST /works/image`：登录并绑定手机号后，提交共享创作简报与 `requestId`，返回应用任务 `id/status/title/createdAt/size/url/error`。每个用户同一请求标识幂等，内容改变拒绝复用标识；并发和提交频率受限。
- `GET /works/image/:id`：当前账号查询并推进保存；`GET /works/image`：本人最近100条任务。后台线程每10秒恢复未完成任务，重启不重新提交模型。
- `GET /image-assets/:id.png`：本人授权或有效签名访问。无签名匿名拒绝，跨账号拒绝，签名过期需从作品接口重新取得。
- `GET /creative-assets`：新增 `images`。画像、既有文字/视频资产接口兼容。
- 参考分析新增 `understanding/understandingRevision`，分析器版本 `content-evidence-3`。旧分析缓存不会冒充新识别结果，场景版本变化或识别失败时不复用语义缓存。
- 共享简报新增 `creativeIntent/referenceNotes/imageRatio`。旧客户端未传时为空或自适应。
- 图片任务保存在既有 `ASSET_ROOT/images/images.sqlite`，图片在同目录 `<id>.png`，不把凭据写入任务数据；换端点后已有任务继续查询原端点，使用当前受控密钥。备份必须包含整个 `ASSET_ROOT/images`。

图片提交超时或结果不确定时，不自动再次提交；原标识仍返回原任务，避免重复扣费。结果读取/下载失败可重试，不重建任务。新一轮生成需用户再次确认；无法确认提交的任务需先核对模型控制台。

## 验证与交付边界

单元与本地HTTP集成使用mock覆盖多模态请求、证据校验、自由表达、可变段落、图片幂等、恢复、下载失败、签名与账号隔离。开发者工具使用仓库外隔离副本，接口改成本机地址并注入mock数据；不把隔离副本的配置带回项目。

尚未部署或提交小程序审核；未执行真实模型调用，因此实际识别质量、图片生成效果、模型开通状态、线上合法域名和真机相册授权仍待部署后验证。图片目前是基于识别内容的文生图，未实现原视频代表帧作为生图参考图的图片编辑接口。图片资产已持久保存，但尚未接入视频资产包的飞书归档功能。

图片实现依据：[万相文生图V2 API参考（wan2.6异步协议）](https://help.aliyun.com/zh/model-studio/text-to-image-v2-api-reference)。图片返回的临时链接在服务端及时下载保存，不作为长期资产地址。
