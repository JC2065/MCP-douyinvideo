# 灵感 AI 统一配置

网页入口：https://youai888.top/youai/admin/ → 热点推荐。小程序“我的 → 管理中台 → 热点推荐”提供相同配置，需要独立管理员登录。localhost:8899 流程设计稿提供真实中台链接，其他规划内容仍是设计预览。

统一管理三个实际调用场景：TA主动推荐、与TA继续对话、热点总结。每个场景可分别启停、选择已注册连接、修改模型ID、5–40秒超时、32–4096输出Token上限和最多1000字补充风格提示词。当前连接是已有国内千问，地址和凭据状态只读；密钥仍由服务器凭据文件/环境变量管理，不下发到客户端。保存后发布才生效，旧对话保留；历史配置可恢复，恢复会新建版本。

配置采用 expectedRevision 防并发覆盖，发生冲突需刷新后重新确认。推荐和总结缓存包含配置版本，暂停后不返回旧缓存。只配置已审核功能的模型和风格，不下发可执行代码或改变用户权限。

状态区分最近业务调用与手动连接检测，显示成功/脱敏失败原因、时间、耗时、模型和HTTP状态。错误可区分凭据权限、限流额度、模型未开通、参数不支持、网络、超时和响应格式。首次上线不补造历史调用记录；尚无记录不代表故障。手动检测会请求少量Token，需要点击确认，检测成功只证明连接，不代表整个业务或物理手机端到端成功。

网页提供最近30次脱敏请求；SQLite仅保留最近1000次请求元数据，业务统计不包含手动检测，不记录提示词、对话正文、账号ID或密钥。配置和状态保存在服务器持久卷的admin/inspiration-ai，配置最多保留50个版本，界面展示最近20个。审计另记发布、恢复和检测操作。

非AI的关键词搜索、榜位监测、我想记本机保存不加入模型路由；来源状态仍在总览查看。点击“把点子做成视频”进入创作服务，其生成模型属于作品产出配置，不混入灵感文本模型配置。
