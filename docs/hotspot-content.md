# 话题内容详情 · 2026-10-15

## 可用流程

首页“查看话题”进入详情，按需获取最多6条相关网页检索摘录，显示标题、摘录、来源域名和检索条目时间。原文通过复制链接在浏览器/原平台查看。热榜变化保留在内容之后。具体抖音视频链接可带入视频下载工具，预填链接后由用户点击解析，不自动下载。

## 数据边界

Bing RSS作为内容检索通路，来源摘录是索引提供的片段，不是AI生成的事件结论，不是已获取的全文。时间字段按“检索条目时间”展示，不当作已核实的发布时间。按标题字符匹配筛选相关结果，去重并拒绝非HTTP(S)链接；相关性和事实仍需核对原文。

本轮没有获取作者、封面或全文，不补造这些字段。微博访客验证和抖音/头条/快手动态页面不能当正文。热榜话题页不能当具体视频解析；只有具体抖音视频链接带入既有解析工具。其他平台原视频仍从原平台链接查阅。本轮不调用付费模型，不自动转写所有热榜视频。

## 服务与缓存

- 公网 `GET /youai/hotspot-content/<平台-20位哈希>`，只接受当前榜单中的话题，不能传任意URL或检索任意关键词。
- 后台固定Bing RSS端点，15秒超时、1MB上限，最多2个并发话题，无无限排队。同一话题请求共享任务。
- 返回pending/ready/empty/error/busy/expired明确状态。前端2秒轮询，最多20次；关闭、离开或切换话题使旧响应失效。
- 成功缓存30分钟，失败/空结果缓存2分钟；显式重试可重新获取失败/空结果，成功缓存不会被重复点击击穿。
- 原子持久化到video-data/hotspots/content，文件最多300个。服务重启后读取缓存。
- 原文结果链接只返回给用户，服务器不会跟随结果URL抓取，避免把内容接口变成任意地址代理。
