# 创作资产与账号资料

创作页“我的创作”合并本机方案、本机视频记录和当前账号云端文字/视频作品。视频按作品ID合并，优先使用刚取回的签名地址；本机毫秒时间和文字服务秒时间分别标准化，按时间倒序。打开旧方案继续编辑，文字按ID读取，视频保留资产包入口。

创作资产页分类：全部、作品、灵感、AI交流、拆解。本机方案/灵感、旧视频索引和拆解记录仍使用原存储，不声称已云同步；云端文字、视频和交流按账号权限读取，每类最近100条。AI交流保留用户提问、AI回答和推荐主题/角度。无云端连接时保留本机列表并明确可重试错误，不用空列表冒充加载成功。旧版本本机数据不做账号归属迁移。图片模型仍未配置。

GET /creative-assets 需要微信会话和已绑定手机号；视频只从账号拥有的run资源读取，返回媒体签名地址，不返回服务端文件路径。POST /auth/profile仅接受nickname、avatar、email，不接受账号ID或手机号修改；昵称1–30字，头像0–7，邮箱格式及254字限制，资料按会话账号持久保存。

用户确认暂不接入发信服务。邮箱仅填写保存，emailVerified固定false，无验证码、邮箱登录或已绑定声明；后续接入发信与验证再开放真正绑定。
