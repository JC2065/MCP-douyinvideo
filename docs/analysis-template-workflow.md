# 多目标拆解与DIY模板

入口：创作 → 拆解工作台；我的 → 拆解方案；案例详情 → 设置。参考视频页面亦可选择素材类型、模板和多选目标，再进入分镜确认。

## 用户流程

1. 选素材类型：口播解说、图文场景、产品展示、操作演示、剧情镜头、优惠促销，分别默认使用通用结构、情绪场景、卖点表达、演示证据、镜头节奏、优惠转化。
2. 按类型组合拆解目标：内容结构、情绪表达、卖点、行动引导、演示证据、镜头节奏。合并重复栏目；不同素材可以保存不同默认目标，具体案例或参考流程也能独立调整。
3. 查看模板问题；点“复制并DIY”，改名称/说明、栏目标题/问题、练习步骤，添加/删除/上下移动栏目。保存后可设为某类素材默认模板，也可统一手动指定。
4. 在案例中切换DIY模板，填写原创主题再应用到草稿；保存作品/版本时保留模板、目标和练习快照。之后编辑或删除模板，不改变旧作品的快照及再生成方法。
5. 参考视频使用模板重点作为生成要求。目标、模板或问题改变时，取消原分镜确认并要求重新确认；前后端均检查所批准分镜里的方案与提交方案一致。

## 约束与真实性

保留旧六预设、自动/手动模式、案例覆盖和存储键，旧草稿仍能加载。最多20个DIY模板，每模板12个自定义栏目与12个练习步骤；叠加目标后的生成问题最多21个。至少保留一个目标及一个栏目；标题/问题必填，字段长度有上限。

原案例结论来自已整理观察；新问题没有证据时显示“未观察到”，不凭模板伪造结论。参考视频的原有画面/音轨分析保持原路径；新增问题是学习与生成重点，不代表视频已被重新智能识别，也不将用户问题当作原片事实。

DIY模板、按素材类型默认模板、多选目标与案例选择现随微信账号保存到云端。每次进入工作台、案例或参考视频页先重新确认微信身份，再加载该账号缓存与云端设置；换账号不会展示上一账号模板。未保存的编辑器草稿不上传，作品/媒体不属于本次同步范围。

修改先写本机再上传；失败保留待同步修改，可点“重新同步”。多设备基于同一旧版本提交时，服务端拒绝覆盖并提示选择“使用云端版本”或“保留本机并上传”；被替换的一份保存在当前设备备份，可显式恢复为新版本。该备份只在本机，不是完整版本历史。编辑中的模板如被较新版本替换，需重新打开或另存为新模板。

首次迁移请先在原手机打开新版拆解工作台，确认“已同步到微信账号”，再在另一手机使用同一微信进入。遇到云端版本冲突，先核对哪份完整再选择，不要直接清理本机缓存。联网识别身份失败时暂停编辑；身份确认后临时网络失败仍保留本机修改。

## 服务与迭代

服务镜像analysis-78包含账号模板持久化与版本冲突保护，并保留analysis-77增加的有界analysisPlan校验、批准方案一致性校验与生成提示词中的模板要求。新字段可省略，旧客户端保持兼容。本次原生编辑器及入口需随新版小程序正常发布；账号同步和原生编辑入口需正常发布新版；云端数据更新不等于客户端可任意加载远程代码。
