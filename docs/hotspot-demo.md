# 热点发现演示

灵感页「热点推荐」提供「当前热榜」「AI 找热点」两个入口，进入同一个页面，随时切换。支持综合与六个平台筛选、话题详情、存入灵感、带入视频创作。

本版没有接入外部热点接口或大模型。24 条素材为人工构造的互动样例，榜单序号仅为演示顺序；没有实时更新时间、真实平台热度或原文链接。公众号等来源也不宣称存在统一官方榜单。

试用：输入「口红」显示六个平台的样例；继续输入「只看平价」，再输入「适合黄皮」，条件累积；「不限」清除角度条件；输入新的主题「咖啡」会重新检索。「新话题」清除本次对话和筛选。还支持旅行、生活。未知关键词显示空结果，不动态捏造标题。

来源适配边界位于 `utils/hotspot-discovery.js`。后续接入时应分别实现榜单与搜索适配、原文 URL、来源时间、可核验的排名/热度、失败与更新时间状态；榜单内容和搜索内容要分别标记。综合推荐不能冒充官方排名，平台热度值不直接横比。AI 只基于检索材料生成摘要与角度。

测试：`node --test tests/*.test.js`。生成视频仍需既有本机视频服务；此模块本身可离线使用。
