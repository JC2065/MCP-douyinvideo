# 我的创作档案

「我的」新增创作方向、视频偏好、关注热点、AI 助手和创作节奏。支持最多五个档案，切换时保存当前修改；每个档案有独立的关键词、时长、感觉和助手设置。

已联动：领域调整演示热点排序；关注关键词成为热点聊天快捷项；平台设置作为初始筛选；视频默认时长/感觉进入采访与合成请求；直接生成跳过采访，先看方案保留确认、隐藏问题；视频首页可关闭本次偏好。明确的点子要求优先。学习形式用于每日一拆，允许临时切换；默认视图回到灵感记录区生效。

每周目标统计本周有完成版本的方案数量（中国时区周一开始，同一作品不重复计算），不等同于已发布视频数。助手说明由用户主动编辑、清空，不根据浏览自动推测。受众/目的和自由说明仅存档，尚无大模型消费，界面明确提示；视频仍只生成无声文字。

「我的方案与模板」复用现有作品与创作口令；素材库、云同步、提醒和自动习惯建议尚未实现。数据为本机存储 `youai-creator-preferences-v1`，恢复默认仅作用于当前档案，不删除作品或其他档案。
