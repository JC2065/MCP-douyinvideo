# 项目 1：YOUAI 布局 MVP

独立 HTML/CSS/JS 交互原型，参考 TDesign 通用页面的信息层级，自行实现；不依赖或复制 TDesign 组件源码。正式小程序与现有 web 原型保持原状。

在仓库根目录用静态 HTTP 服务打开 `/web/project-1/`。也可直接打开本目录 index.html（浏览器可能限制本地存储）。默认展示创作页，底部切换灵感、创作、学习、我的。

## 布局决策

- 色彩：主蓝 #0052d9、正文 #17243b、次要文字 #66748b、背景 #f5f7fb、浅蓝 #eaf1ff、白色 #ffffff。
- 字体：PingFang SC / Microsoft YaHei；页面标题 27px、分区标题 16px、内容 13–14px。左对齐，页面横向留白 20px。
- 主次：创作主入口 → 两个辅助起点 → 六工具三列网格 → 最近作品。主要创作入口使用蓝色，其余区域以留白区分层次。
- 桌面展示说明与手机预览；450px 以下填满窗口，固定底部导航并留安全区。

## 可体验与边界

四页切换、点子本地保存与刷新恢复、创作方向表单、预设分镜及明确确认、学习分类、工具输入和静态提词阅读。示例作品/案例/分镜均为预览内容；不调用云端、不进行视频解析或生成、不保存正式偏好。数据键 `youai-layout-project1-ideas` 独立于正式应用。
