参考视频分析、分镜、生成任务、成本、产物血缘与反馈的数据边界见[视频资产与生成任务契约](docs/video-asset-pipeline.md)。

抖音参考入口现在严格区分链接识别与媒体获取。本机已接入自托管 Douyin_TikTok_Download_API v5.1.3，凭据只由视频服务读取，小程序使用“我的 → 工具接口管理 → 视频下载 / 参考解析”中的平台公共服务状态，不接触密钥。视频服务把原短链交给 `/api/v1/parse?wait=30`，只选择解析结果中的视频主地址和视频流，下载时携带抖音来源页请求头并在 CDN 地址受限时尝试备用视频地址；只接受 HTTPS 媒体地址，并在 200MB 限制内完成下载、SHA-256 去重和 FFmpeg 解码验证。短链失效、解析器凭据失效、媒体下载受限和一般解析失败会显示对应恢复提示；失效短链要求重新复制分享链接或上传原视频，不会仅凭分享文案替换成可能错误的视频。

本机解析链路由 `scripts/ensure-video-stack.ps1` 自检和恢复：先检查 DTK `/readyz` 与 YOUAI `/health`，必要时启动 Docker Desktop、用 Compose `--wait` 恢复解析依赖，再以仓库外凭据启动视频网关。运行 `scripts/install-video-stack-watchdog.ps1` 后会在登录时及每 5 分钟检查一次，禁止并发重复拉起；可用 `scripts/uninstall-video-stack-watchdog.ps1` 完整移除计划任务。运行日志位于 `E:\data\codexYOUAI-data\logs`，不写入仓库。

“高度参考原片”通过独立媒体中继和 Cloudflare Tunnel 把 15 秒以内的已验证原片交给 Wan：中继仅监听 `127.0.0.1:8766`，公网只允许健康检查和 30 分钟有效的 HMAC 签名原片地址，不暴露任务或资产管理接口；密钥与动态公网地址保存在 `E:\data\codexYOUAI-data`。方向页会检测通道，只有公网 HTTPS 实际可访问时才允许选择高度参考。容器或音频尾帧造成的 15.00–15.50 秒小幅超限会自动规范为 14.9 秒派生素材并保留原片与 SHA-256 血缘，明显超过 15 秒仍要求选择画面风格或手工裁剪。当前 TryCloudflare 适合本机 Demo且不收取额外存储费用，但没有生产可用性保证；正式部署应改用 Cloudflare 命名 Tunnel 或 S3/OSS 临时对象地址。

解析等待期间，输入卡会显示“识别链接 → 平台解析 → 下载素材 → 校验视频”四阶段、已等待时长和当前动作。处理中阶段用于解释等待，最终成功或失败以视频服务实际返回为准；成功后展示分辨率、时长和文件大小。

最近生成会按创作来源形成可辨识标题：点子取原始主题，抖音参考取解析后的原视频标题，模板口令取本次填写的主题；列表同时标注“点子创作 / 抖音参考 / 模板口令”和资产包状态。旧记录会兼容为“来源 + 生成时间”，不再重复显示通用创作指令。

素材取得后会自动进入 `ReferenceAnalysis v1`：抽取代表帧、测量画面变化、识别音轨文案，并形成开场钩子、三段结构、镜头节奏、画面证据、可复用策略、限制和置信度。同一 SHA-256 会复用分析缓存。自动转写需要用户校对；未识别到的字幕或画面语义不会由分享标题补齐。

生成前采用四阶段沟通：选择起点 → 对齐创作意图 → 审核分镜 → 生成成片。方向页确认结果、受众、开场、语气、画面、结尾和时长，并可填写必须出现与不要出现；参考视频可选择高度参考原片、画面风格、内容结构或同题新作。默认“画面风格”会从已验证原片抽取最多 3 张代表帧并作为 `reference_image` 真正提交给模型；“高度参考原片”需要配置模型可访问的 HTTPS 素材地址和签名密钥，原片不超过 15 秒时才以限时 `reference_video` 提交。配置不满足时会在付费调用前明确拦截，不会静默退化成纯文字生成。系统先形成可编辑的开场、展开、收束三段故事板，用户明确确认后才调用视频模型。

选择“AI 生成画面”时，方向页允许用户修改 Wan3.0 的实际生成参数：全能或首尾帧模式、480P/720P/1080P、自动/21:9/16:9/4:3/1:1/3:4/9:16、2–30 秒或智能时长、有声/静音、提示词优化和 AI 水印。默认采用 720P、9:16、有声、提示词优化、无水印以平衡成本和短视频使用场景；智能时长向 Provider 提交 `-1`。首尾帧模式只对已验证参考原片开放，服务端抽取首帧与尾帧并且不再混用 `reference_image` 或 `reference_video`；高度参考原片还会在提交前校验输入视频与输出时长合计不超过 30 秒。最终参数随资产包保存，可在成片资产详情复核。

提交成片任务时只传递分析证据、分析状态和素材 SHA-256，不重复传递本地文件路径及下载元数据。生成接口允许最多 64 KB 请求；解析、分析和配置接口采用各自更小的上限，超限或 JSON 损坏会返回对应错误。

每次成功生成都会建立 `video-asset-bundle-v1` 资产包。默认持久目录为 `E:\data\codexYOUAI-data\video-assets`：原片按 SHA-256 保存到 `sources`，代表帧保存到 `keyframes`，每次运行在 `runs/<运行ID>` 中保存分析、故事板版本、脱敏请求、实际提示词、最终 MP4 和血缘清单；同一份元数据事务写入 PostgreSQL 的媒体、分析、镜头、故事板、生成任务和产物表。成片页“查看本次资产”可检查保存状态。当前整片 Provider 只返回最终视频，因此不会伪造逐镜头候选；生成后反馈资产将在下一阶段接入。

小程序中的个人解析配置入口为“我的 → 更多设置 → 工具接口管理 → 视频下载 / 参考解析”。填写自托管服务的 HTTPS 根地址和可选 Bearer Token，保存后点击“检测参考解析服务”；检测通过 7 天内创作页可使用，失败或过期会要求重新检测。配置只保存在本机，创作时临时提交给本机视频服务，不写入作品历史。

视频资产可从“我的 → 视频资产”集中查看和管理。当前设备只保存最近生成索引；长期文件位于 `E:\data\codexYOUAI-data\video-assets`，其中参考原片按 SHA-256 去重，单次运行位于 `runs/<runId>/`；资产元数据同步到 PostgreSQL。资产页支持重新打开成片、查看资产清单和移除当前设备索引。移除索引不会删除长期文件或数据库记录；需要引用检查与可恢复删除后才开放长期资产清理。

成片页的资产清单每一行都可点击展开：参考原片可播放，内容分析可查看摘要与代表帧，沟通答案与三段故事板、Provider 与实际脱敏提示词、最终成片血缘均可直接查看。客户端只取得受控预览 URL 和业务字段，不返回服务器绝对路径、请求文件路径或凭据。

后端本地及未来云端的运行方式、备份目标和迁移关卡见[后端运行与云迁移设计](docs/cloud-runtime-design.md)。当前仅完成运行基座与首批数据库迁移，尚未部署线上服务。

面向普通短视频创作爱好者，提供灵感、创作、学习、任务、我的五个入口。采用微信原生 WXML/WXSS/JS，底部为自定义五入口导航。文本和学习演示可离线使用；视频创作需启动本机服务，并由服务端调用第三方视频模型或本机文字合成器。

## 最近进展（2026-10-10 至 2026-10-11）

- 创作首页统一为三个视频入口：输入点子、粘贴抖音短视频链接、粘贴模板口令；三种来源进入同一套“选择起点 → 确认方向 → 生成成片”流程。
- 成片方向只确认核心目标、画面形式和时长。时长支持 2–30 秒拖动，默认 2 秒；“智能”会根据输入内容估算时长。
- 抖音链接粘贴后由本机服务交给自托管解析器，页面明确显示识别、解析、下载、校验和后续内容分析进度；失败时不会进入生成。只有取得并验证原视频后，才会使用画面和音轨产出 `ReferenceAnalysis v1`。代表帧支持智能、精简、标准和细致四档，约按每 3、6、3、2 秒选择密度；采样点位于各时间段中部，单点失败会精确重试，并在至少保留 3 张有效帧时降级完成。
- “AI 生成画面”提交已配置的千问 `wan3.0-video` 异步任务，轮询成功后下载 MP4 给小程序播放和保存；“纯文字画面”继续使用本机 FFmpeg 合成。API Key 只从本机环境变量或 MoneyPrinterTurbo 的 `config.toml` 读取，不写入小程序和本仓库。
- 生成等待页展示提交、排队、生成和取回成片的真实阶段、已等待时间及任务号缩写，每 2 秒查询一次；页面最长等待 30 分钟，与服务端第三方任务上限一致。
- 本机服务启动：`powershell -ExecutionPolicy Bypass -File scripts/start-video-server.ps1`，脚本从仓库外的凭据文件注入解析器地址和密钥；也可直接运行 `C:\Users\one\MoneyPrinterTurbo\.venv\Scripts\python.exe scripts/video-server.py` 启动不带解析器配置的服务。小程序开发环境请求 `http://127.0.0.1:8765`；真机或上线需改为可访问的 HTTPS 服务并配置微信合法域名。

## 推荐完整演示顺序

### 灵感、创作、学习闭环

1. 在“我的记录”保存自己的主题，或从“热点推荐”选择一个角度。热点是编辑精选示例，不是实时热榜。
2. 开始创作后点击“从学习案例中选方法”，阅读案例并应用；自己的主题和灵感来源会保留。已有编辑内容被替换前会请求确认。
3. 按自己的场景调整人群、钩子、内容证据和行动引导，保存草稿或完成创作方案。来源、参考案例和完成版本保存在本机，重新进入可继续编辑。
4. 在“我的创作”点击“复盘 → 新灵感”，记录实际观察、拍摄前自检或下次改进，保存到“我的记录”，开始下一轮创作。同一作品再次保存复盘会更新对应记录。

文本创作仍支持可编辑、可保存、可追溯来源的方案，并可将复盘转成下一条灵感。视频创作已接入第三方 AI 画面生成和本机纯文字成片；配音、音乐、自动发布、实时热点，以及参考视频的完整视听语义复刻尚未接入。

### 创作口令

从案例复制方法，或从“我的创作”复制已保存方案为口令。进入“创作 → 创作口令”，粘贴口令、查看核心思路、填写自己的主题，一键生成可编辑草稿，再保存或完成方案。没有口令时可试用三个原创教学模板。

口令含方法名称、核心思路及主题模板，跟随草稿保存，重开可换主题再生成。口令仅作本地文本解析，不执行代码，不自动读取剪贴板。复制作品会包含当前方案文本，界面提示分享前检查。空主题、损坏、未知版本、超长口令会提示错误；有效口令可进入统一视频生成流程。

### 任务演示

1. 灵感记录“咖啡店的秋日新品”，转为创作，生成脚本并完成作品。
2. 个人身份进入咖啡任务，点击申请接单。
3. 在我的切换商家，再进入该任务，选定创作者。
4. 切回个人，进入任务，选择刚完成的作品提交。
5. 切回商家，填写修改建议并要求修改。
6. 切回个人，在创作修改作品并再次完成，进入任务重新提交。
7. 商家验收通过，进入我的 → 订单与收益查看模拟结算。
8. 可再用商家身份发布新任务，切到个人申请自己的演示任务。

## 演示边界

数据仅保存在微信本地存储中，重启编译可保留；清理缓存或重置会删除。角色共用一套演示数据，用于展示双方流程，不是多用户权限系统。

文本方案中的部分 AI 表现仍为固定模板，热点为编辑精选示例。视频生成页通过本机服务联网调用第三方模型；视频案例继续使用人工核实的页面元数据与有限画面观察，并将未核实部分明确标注。任务、支付、提现、授权交易和作品商城仍是本地演示数据。任务提交记录作品标题、版本号与该版本的文本快照；完整历史保存在作品版本中。商家可管理所有示例任务。

## 验证

## 视频播放修复与后续扩展

旧播放器直接使用代码包 MP4 路径，在用户模拟器中出现 00:00 和播放失败。文件已通过 H.264/AAC 完整解码检查，但未取得旧播放器底层错误日志，因此不能将所有原因归结为路径。现改为离线视频数据随案例分包加载，使用 FileSystemManager.writeFile（base64）写入 wx.env.USER_DATA_PATH，准备完成后才创建 video 组件。保留版本化缓存、按长度检测不完整文件、强制重建重试及具体错误信息。此方法仅用于单条离线 Demo，不能批量嵌入生产视频。

重新编译后进入学习 → 案例87 → 等待本地视频准备 → 播放。错误时点击重新加载；仍失败时查看页面错误信息和开发者工具 Console。自动测试不代替微信模拟器或真机解码验证。

生产建议：上传原片 → 对象存储或云点播 → 异步转码、封面、审核 → CDN → 小程序播放。数据库仅保存视频ID、时长、封面地址、播放版本和拆解时间点。业务API负责查询和权限，不中转视频字节。

初期短片可使用 H.264/AAC + faststart MP4，支持 HTTP Range 和 CDN 缓存，按原片分辨率输出合适码率，不将480p原片放大成高清。长视频及弱网再评估多码率HLS与所选微信播放器的实际兼容性。列表仅加载封面，进入详情才加载视频；不要一次预下载全部视频。只有采用支持预加载的播放器并验证带宽收益后，才预加载下一条。

对外播放采用 HTTPS；按实际视频组件及请求/下载API配置小程序域名。私有内容使用服务端签名URL及过期刷新，设置合理CDN缓存策略。上线后监控首帧时间、播放错误、卡顿率、CDN命中率与流量成本，并用真机和弱网测试判断优化效果。

官方资料：https://cloud.tencent.com/document/product/266/38081 （小程序点播）；https://cloud.tencent.cn/document/product/266/78295 （CDN分发）。
